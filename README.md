# AÉREA — GitHub Pages

Landing page para servicios de fotografía, video y producción aérea en El Salvador.

## Archivos públicos para GitHub Pages
- `index.html`
- `styles.css`
- `script.js`
- `logo-aerea.png`
- `favicon-32.png`
- `favicon-512.png`
- `apple-touch-icon.png`

## Backend
`Code.gs` se mantiene solamente en Google Apps Script. No lo publiques en GitHub porque contiene el correo de destino.

El `script.js` ya contiene la URL `/exec` del Web App configurado para el formulario.

## Google Sheets + correo
El flujo es:

Formulario → Google Apps Script → Google Sheets → correo personal

## Diseño
Incluye favicon/logo AÉREA, animaciones al hacer scroll, barra de progreso, marquee, contador, efecto de cursor, tarjetas con movimiento, hero animado y sección de ubicaciones centrada en San Salvador y cobertura de El Salvador.

Las imágenes de muestra siguen siendo de Unsplash; sustitúyelas por material propio antes de publicar el sitio comercialmente.
